# Car Rental System 🚗

A Java-based Car Rental System developed using Object-Oriented Programming (OOPs) concepts.
This project allows users to rent and return cars through a menu-driven console application.

## Features

* View Available Cars
* Rent a Car
* Return a Car
* Customer Management
* Rental Information

## Technologies Used

* Java
* OOPs Concepts
* ArrayList
* Scanner Class

## OOPs Concepts Used

* Encapsulation
* Classes & Objects
* Abstraction
* Polymorphism

## How to Run

1. Open the project in VS Code
2. Compile the program:
   javac src/Main.java
3. Run the program:
   java -cp src Main
